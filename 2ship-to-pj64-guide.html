Majora's Mask · save conversion

Move a 2Ship2Harkinian save to Project64

2Ship stores saves as JSON. Project64 expects the 128 KB FlashRAM image the original cartridge used. A small converter rebuilds that image from your JSON, including your owl save, so you can carry on in the emulator.

US (NTSC-U) ROM only Project64 3.x Windows ~5 minutes

Before you start

  • The converter, 2ship-to-pj64.exe. Nothing needs installing. If you'd rather not run an exe, use the Python script at the bottom of this page instead.
  • A US Majora's Mask ROM in Project64. The Japanese and European releases arrange their save data differently and won't read this file.
  • Your 2Ship save. It's in the saves folder next to 2ship.exe: file1.json is file slot 1 and file2.json is slot 2. The …backup.json files are copies.

Steps

  1. Close Project64

    While a game is running, Project64 keeps its own copy of the save and writes it back to disk. If it's open while you convert, it can overwrite your new save.

  2. Open the converter and choose your save

    Double-click 2ship-to-pj64.exe and click Browse… next to Choose your 2Ship save. Or drag your save onto the exe to open it with the save already chosen.

    Your saves are in the saves folder next to 2ship.exe. file1.json is 2Ship's file slot 1 and file2.json is slot 2. Once you choose one, the converter shows the player name, hearts, masks and whether there's an owl save, so you can check it's the right file.

    Windows may warn you the first time. The exe isn't signed, so SmartScreen can show "Windows protected your PC". Click More info, then Run anyway. Some antivirus programs also flag small packaged Python tools like this one by mistake.

  3. Choose where to save it

    The quickest way is to write straight into Project64's save file. To find it, open Project64 and go to Options → Settings → Directories → Native saves. If that's unset, saves are in the Save folder inside the Project64 install folder.

    Majora's Mask uses a subfolder named after the ROM, such as ZELDA MAJORA'S MASK-FC392084…. Click Browse… next to Choose where to save it and pick the ZELDA MAJORA'S MASK.fla inside that subfolder.

    If the subfolder doesn't exist yet, start the game once, create a throwaway file on the file select screen so the game saves, then close Project64. Or save the new file anywhere for now and copy it into that subfolder later.

    Leave the format on Project64 format. The other option writes cartridge byte order for emulators like mupen64plus or Ares.

  4. Choose a file slot

    Pick Slot 1 or Slot 2. Each card shows what that slot holds now, so you can see what you'd replace. The converter asks before replacing a slot that already has a save.

    With Keep the other slot from the existing file ticked, only the slot you pick changes. Back up the existing file first saves a dated .bak copy next to it before anything is written.

  5. Convert and play

    Click Convert save, then start Majora's Mask in Project64. Your file is in the slot you chose. If you had an owl save, the file select screen shows it, and loading it deletes it just like on the original cartridge. Otherwise you start from your last Song of Time save.

Song of Time save (the one you reset to)Yes
D-pad item assignments, playtime, file creation dateNo. These are 2Ship-only and the original game has nowhere to store them.
2Ship enhancement or randomizer stateNo

How the file is laid out

The output is the same 128 KB FlashRAM image the US cartridge writes. Every save is written twice, because the game falls back to the backup copy if a checksum fails.

OffsetSizeContents
0x000000x100CFile 1 Song of Time save
0x020000x100CFile 1 Song of Time save (backup)
0x040000x100CFile 2 Song of Time save, plus backup at 0x06000
0x080000x3CA0File 1 owl save
0x0C0000x3CA0File 1 owl save (backup)
0x100000x3CA0File 2 owl save, plus backup at 0x14000
0x180000x0006Options header (0xA51D, language, sound), plus backup at 0x1C000

Each save starts with the text ZELDA3 0x24 bytes in. Its checksum is a plain 16-bit sum of every byte in the save, worked out with the checksum field set to zero.

Why the checksums differ from 2Ship's. 2Ship's checksum also covers its own extras (playtime, D-pad items), which the original game doesn't store. The converter writes the checksum the original game checks, so a mismatch with the number in the JSON is expected.

Why there are two output files

The N64 is big-endian. Project64 stores FlashRAM with each 4-byte word reversed, so the same bytes look different on disk:

5A454C44
Cartridge order: "ZELD"
444C455A
Project64 order: "DLEZ"

Use ZELDA MAJORA'S MASK.fla for Project64. The .bigendian.fla copy is in cartridge order, for emulators such as mupen64plus or Ares, or for flash cart tools.

Troubleshooting

The file slot is empty

Check the ROM is the US version, and that the file is named exactly ZELDA MAJORA'S MASK.fla in the subfolder Project64 actually uses. If unsure, save once in-game, see which file Project64 changes, and put yours in its place.

The file was replaced by an old save

Project64 was probably still running when you copied the file in, and wrote over it on exit. Close it fully and copy the file again.

"A device which does not exist was specified" when copying

Your save folder is inside OneDrive, and OneDrive isn't syncing. Resume sync or restart OneDrive from the tray icon, then try again. If you renamed a backup there while OneDrive was stuck, check it's still there afterwards, or check the OneDrive recycle bin.

The script stops with an AssertionError

The save's structure doesn't match what the script expects. This can happen with a much older or newer 2Ship save format. Check that "type" at the bottom of the JSON says 2S2H_SAVE. This guide was written against format version 7.

Python alternative

The exe is this script packaged with Python. If you'd rather run the script yourself, install Python 3 from python.org, save the script below as convert.py, and run:

python convert.py "C:\path\to\2Ship2Harkinian\saves\file1.json"

Add --file 2 to force file slot 2, or add an output path after the save to write somewhere else.

"""Convert a 2Ship2Harkinian JSON save (file1.json) into an N64 Majora's Mask (US) FlashRAM image.

Usage:
  python convert.py <input.json> [<output.fla>] [--file 1|2]

Without an output path, "ZELDA MAJORA'S MASK.fla" is written next to the input file.
The slot defaults to the number in the file name (file2.json -> slot 2), otherwise slot 1.
The 2ship-to-pj64 app (gui.py) uses the same code and can also merge into an existing save file.
Writes the image in Project64's word-swapped byte order (and a big-endian copy next to it).
"""
import json, os, re, shutil, struct, sys, time

def u8(v): return struct.pack('>B', v & 0xFF)
def s8(v): return struct.pack('>b', v)
def u16(v): return struct.pack('>H', v & 0xFFFF)
def s16(v): return struct.pack('>h', v)
def u32(v): return struct.pack('>I', v & 0xFFFFFFFF)
def s32(v): return struct.pack('>i', v)
def u64(v): return struct.pack('>Q', v & 0xFFFFFFFFFFFFFFFF)
def chars(lst): return bytes(c & 0xFF for c in lst)


def player_data(p):
    b = chars(p['newf']) + u16(p['threeDayResetCount']) + chars(p['playerName'])
    b += s16(p['healthCapacity']) + s16(p['health']) + s8(p['magicLevel']) + s8(p['magic'])
    b += s16(p['rupees']) + u16(p['swordHealth']) + u16(p['tatlTimer'])
    b += u8(p['isMagicAcquired']) + u8(p['isDoubleMagicAcquired']) + u8(p['doubleDefense']) + u8(p['unk_1F'])
    b += u8(p['unk_20']) + b'\0' + u16(p['owlActivationFlags']) + u8(p['unk_24']) + b'\0' + s16(p['savedSceneId'])
    assert len(b) == 0x28
    return b


def equips(e):
    b = b''.join(chars(r) for r in e['buttonItems']) + b''.join(chars(r) for r in e['cButtonSlots'])
    b += u16(e['equipment'])
    assert len(b) == 0x22
    return b


def inventory(i):
    b = chars(i['items']) + b''.join(s8(a) for a in i['ammo'])
    b += u32(i['upgrades']) + u32(i['questItems']) + chars(i['dungeonItems'])
    b += b''.join(s8(k) for k in i['dungeonKeys']) + s8(i['defenseHearts'])
    b += b''.join(s8(f) for f in i['strayFairies'])
    b += b''.join(chars(n) for n in i['dekuPlaygroundPlayerName'])
    b += b'\0\0'  # pad to 0x88
    assert len(b) == 0x88, hex(len(b))
    return b


def save_info(s):
    b = player_data(s['playerData'])
    b += equips(s['equips']) + b'\0\0'  # 0x22 bytes + pad so Inventory starts at 0x4C
    b += inventory(s['inventory'])
    assert len(b) == 0xD4
    for f in s['permanentSceneFlags']:
        for k in ('chest', 'switch0', 'switch1', 'clearedRoom', 'collectible', 'unk_14', 'rooms'):
            b += u32(f[k])
    assert len(b) == 0xDF4
    b += chars(s['unk_DF4'])
    b += b''.join(u32(x) for x in s['dekuPlaygroundHighScores'])
    b += u32(s['pictoFlags0']) + u32(s['pictoFlags1']) + u32(s['unk_E5C']) + u32(s['unk_E60'])
    b += b''.join(u32(x) for x in s['unk_E64'])
    b += b''.join(u32(x) for x in s['scenesVisible'])
    b += u32(s['skullTokenCount']) + u32(s['unk_EA0']) + u32(s['unk_EA4'])
    b += b''.join(u32(x) for x in s['unk_EA8'])
    b += u32(s['stolenItems']) + u32(s['unk_EB4'])
    b += b''.join(u32(x) for x in s['highScores'])
    assert len(b) == 0xED4, hex(len(b))
    b += chars(s['weekEventReg'])
    b += u32(s['regionsVisited']) + u32(s['worldMapCloudVisibility'])
    assert len(b) == 0xF40
    b += u8(s['unk_F40']) + u8(s['scarecrowSpawnSongSet']) + chars(s['scarecrowSpawnSong'])
    b += s8(s['bombersCaughtNum']) + b''.join(s8(x) for x in s['bombersCaughtOrder'])
    b += b''.join(b''.join(s8(x) for x in row) for row in s['lotteryCodes'])
    b += b''.join(s8(x) for x in s['spiderHouseMaskOrder'])
    b += b''.join(s8(x) for x in s['bomberCode'])
    assert len(b) == 0xFDC
    h = s['horseData']
    b += s16(h['sceneId']) + s16(int(h['pos']['x'])) + s16(int(h['pos']['y'])) + s16(int(h['pos']['z'])) + s16(h['yaw'])
    b += u16(0)  # checksum placeholder
    assert len(b) == 0xFE8
    return b


def save(sv):
    b = s32(sv['entrance']) + u8(sv['equippedMask']) + u8(sv['isFirstCycle']) + u8(sv['unk_06']) + u8(sv['linkAge'])
    b += s32(sv['cutsceneIndex']) + u16(sv['time']) + u16(sv['owlSaveLocation'])
    b += s32(sv['isNight']) + s32(sv['timeSpeedOffset']) + s32(sv['day']) + s32(sv['eventDayCount'])
    b += u8(sv['playerForm']) + u8(sv['snowheadCleared']) + u8(sv['hasTatl']) + u8(sv['isOwlSave'])
    assert len(b) == 0x24
    b += save_info(sv['saveInfo'])
    assert len(b) == 0x100C
    return bytearray(b)


def owl_context(o):
    b = save(o['save'])
    b += chars(o['eventInf']) + u8(o['unk_1014']) + u8(o['bButtonStatus']) + u16(o['jinxTimer'])
    b += s16(o['rupeeAccumulator']) + chars(o['bottleTimerStates'])
    assert len(b) == 0x1020
    for k in ('bottleTimerStartOsTimes', 'bottleTimerTimeLimits', 'bottleTimerCurTimes', 'bottleTimerPausedOsTimes'):
        b += b''.join(u64(x) for x in o[k])
    assert len(b) == 0x10E0
    b += chars(o['pictoPhotoI5'])
    assert len(b) == 0x3CA0, hex(len(b))
    return b


CHECKSUM_OFS = 0x24 + 0xFE6
FLASH_SIZE = 0x20000
OUT_NAME = "ZELDA MAJORA'S MASK.fla"
OPTIONS_OFS = (0x18000, 0x1C000)
OPTIONS_ID = b'\xA5\x1D'
# Per slot: the Song of Time save (main + backup copy, 0x4000 bytes) and the owl save (main + backup, 0x8000 bytes)
NEW_CYCLE_OFS = {1: 0x0000, 2: 0x4000}
OWL_OFS = {1: 0x8000, 2: 0x10000}


def finalize(buf):
    """Write the game's checksum (16-bit byte sum, computed with the field zeroed). Returns it."""
    buf[CHECKSUM_OFS:CHECKSUM_OFS + 2] = b'\0\0'
    c = sum(buf) & 0xFFFF
    buf[CHECKSUM_OFS:CHECKSUM_OFS + 2] = u16(c)
    return c


def word_swap(data):
    """Reverse every 4-byte word. Converts between cartridge order and Project64's order (both directions)."""
    out = bytearray(len(data))
    for i in range(0, len(data) - len(data) % 4, 4):
        out[i:i + 4] = data[i:i + 4][::-1]
    return out


def load_save(path):
    with open(path, encoding='utf-8') as f:
        d = json.load(f)
    if not isinstance(d, dict) or d.get('type') != '2S2H_SAVE':
        raise ValueError('this is not a 2Ship2Harkinian save file')
    return d


def slot_from_filename(path):
    """file2.json / file2backup.json -> 2, anything else -> 1."""
    m = re.match(r'file([12])', os.path.basename(path), re.I)
    return int(m.group(1)) if m else 1


# ---- reading names and stats, for showing what's in a save ----

def decode_name(raw):
    s = ''
    for c in raw:
        if c <= 0x09: s += chr(ord('0') + c)
        elif c <= 0x23: s += chr(ord('A') + c - 0x0A)
        elif c <= 0x3D: s += chr(ord('a') + c - 0x24)
        elif c == 0x3E: s += ' '
        elif c == 0x40: s += '.'
        elif c == 0x3F: s += '-'
        else: s += '?'
    return s.strip() or '(no name)'


def describe_json(d):
    """Short facts about a 2Ship save, for the preview panel."""
    owl = d.get('owlSave')
    has_owl = bool(owl and owl['save'].get('isOwlSave'))
    # Describe the save the player will actually load: the owl save if there is one.
    cur = owl['save'] if has_owl else d['newCycleSave']['save']
    p = cur['saveInfo']['playerData']
    inv = cur['saveInfo']['inventory']
    info = {
        'name': decode_name(p['playerName']),
        'hearts': p['healthCapacity'] / 16,
        'masks': sum(1 for x in inv['items'][24:48] if x != 255),
        'rupees': p['rupees'],
        'cycles': p['threeDayResetCount'],
        'owl': has_owl,
    }
    if has_owl:
        s = owl['save']
        mins = s['time'] * 24 * 60 // 0x10000
        info['owl_day'] = s['day']
        info['owl_time'] = f'{mins // 60:02d}:{mins % 60:02d}'
    return info


def to_native(raw, assume_pj64=True):
    """Return (cartridge-order flash image, detected format) for an existing .fla file."""
    data = bytearray(raw[:FLASH_SIZE]) + bytearray(max(0, FLASH_SIZE - len(raw)))
    swapped = word_swap(data)
    for ofs in OPTIONS_OFS + (0x24, 0x4024, 0x8024, 0x10024):
        if data[ofs:ofs + 2] == OPTIONS_ID or data[ofs:ofs + 6] == b'ZELDA3':
            return data, 'big-endian'
        if swapped[ofs:ofs + 2] == OPTIONS_ID or swapped[ofs:ofs + 6] == b'ZELDA3':
            return swapped, 'project64'
    return (swapped, 'project64') if assume_pj64 else (data, 'big-endian')


def describe_flash(native):
    """What each slot of a cartridge-order flash image holds: {1: str, 2: str}."""
    out = {}
    for slot in (1, 2):
        parts = []
        for ofs, kind in ((NEW_CYCLE_OFS[slot], ''), (OWL_OFS[slot], 'owl')):
            for copy in (0, 0x2000 if not kind else 0x4000):
                base = ofs + copy
                if native[base + 0x24:base + 0x2A] == b'ZELDA3':
                    name = decode_name(native[base + 0x2C:base + 0x34])
                    parts.append(f'{name}, owl save' if kind else name)
                    break
        if not parts:
            out[slot] = 'empty'
        elif len(parts) == 2 and parts[1].startswith(parts[0]):
            out[slot] = parts[1]
        else:
            out[slot] = parts[0]
    return out


# ---- building and writing ----

def build_slot(d, flash, slot):
    """Write save `d` into `flash` (cartridge order) at `slot`, replacing whatever was there. Returns checksums."""
    if slot not in (1, 2):
        raise ValueError('file slot must be 1 or 2')
    nc_ofs, owl_ofs = NEW_CYCLE_OFS[slot], OWL_OFS[slot]
    flash[nc_ofs:nc_ofs + 0x4000] = bytes(0x4000)
    flash[owl_ofs:owl_ofs + 0x8000] = bytes(0x8000)

    nc = d['newCycleSave']['save']
    ncb = save(nc)
    sums = {'new-cycle save': (finalize(ncb), nc['saveInfo']['checksum'])}
    flash[nc_ofs:nc_ofs + len(ncb)] = ncb
    flash[nc_ofs + 0x2000:nc_ofs + 0x2000 + len(ncb)] = ncb

    o = d.get('owlSave')
    if o and o['save'].get('isOwlSave'):
        ob = owl_context(o)
        sums['owl save'] = (finalize(ob), o['save']['saveInfo']['checksum'])
        flash[owl_ofs:owl_ofs + len(ob)] = ob
        flash[owl_ofs + 0x4000:owl_ofs + 0x4000 + len(ob)] = ob

    for ofs in OPTIONS_OFS:
        if flash[ofs:ofs + 2] != OPTIONS_ID:
            flash[ofs:ofs + 6] = OPTIONS_ID + u8(1) + u8(0) + u8(0) + u8(0)
    return sums


def write_flash(d, dst, slot, pj64=True, merge=True, backup=True, bigendian_copy=False):
    """Convert save `d` into slot `slot` of `dst`. Returns a dict describing what happened."""
    result = {'path': dst, 'backup': None, 'merged': False, 'extra': None}
    flash = bytearray(FLASH_SIZE)
    if os.path.exists(dst):
        with open(dst, 'rb') as f:
            raw = f.read()
        if backup:
            stamp = time.strftime('%Y-%m-%d_%H%M%S')
            result['backup'] = f'{dst}.{stamp}.bak'
            n = 2
            while os.path.exists(result['backup']):
                result['backup'] = f'{dst}.{stamp}-{n}.bak'
                n += 1
            shutil.copy2(dst, result['backup'])
        if merge:
            flash, _ = to_native(raw, assume_pj64=pj64)
            result['merged'] = True
    result['checksums'] = build_slot(d, flash, slot)
    with open(dst, 'wb') as f:
        f.write(word_swap(flash) if pj64 else flash)
    if bigendian_copy:
        result['extra'] = dst.rsplit('.', 1)[0] + '.bigendian.fla'
        with open(result['extra'], 'wb') as f:
            f.write(flash)
    result['slots'] = describe_flash(flash)
    return result


def main():
    """Command line: python convert.py <input.json> [<output.fla>] [--file 1|2]"""
    args = sys.argv[1:]
    slot = None
    if '--file' in args:
        i = args.index('--file'); slot = int(args[i + 1]); del args[i:i + 2]
    if not args:
        print(__doc__)
        sys.exit(2)
    src = args[0]
    dst = args[1] if len(args) > 1 else os.path.join(os.path.dirname(os.path.abspath(src)), OUT_NAME)
    slot = slot or slot_from_filename(src)
    try:
        d = load_save(src)
        print(f'Converting {src}  ->  file slot {slot}')
        r = write_flash(d, dst, slot, merge=False, backup=False, bigendian_copy=True)
    except Exception as e:
        print(f'Conversion failed: {e!r}')
        sys.exit(1)
    for label, (mine, theirs) in r['checksums'].items():
        print(f'{label}: checksum {mine} (2Ship stored {theirs})')
    print('Wrote', r['path'])
    print('  and', r['extra'])


if __name__ == '__main__':
    main()
